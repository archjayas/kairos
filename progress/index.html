    Progress and badges¶

    Kairos keeps track of what you've done and awards a badge at each stage. You don't check anything off: the scripts notice when you reach a milestone, and tell you when you earn a badge.

    python progress.py

    This prints your progress in the terminal and opens a page with your badges and a timeline of what you've done. Progress is saved on your computer only, in .kairos/progress.json. Nothing is sent anywhere.

    Your badges also appear on the website's home page when you preview it locally with mkdocs serve. Hover a badge to see what it means. On a published site, the home page shows all five as a preview instead: your personal progress is never published.

    Your badges so far¶

    Earn five badges as you learn. Kairos notices what you do and awards them automatically. Hover a badge to see what it means. This is a preview: your own badges stay on your computer. To see them, run python progress.py, or preview this site locally with mkdocs serve.

    • First AgentFirst AgentEarn it as you goFor building your first tool-calling agent, seeing the approval gate work, and running your first eval.How: Run the free eval, then schedule a meeting with the Claude agent (Quickstart steps 2-4).
    • EvaluatorEvaluatorEarn it as you goFor measuring a real model against the golden set, not just the free baseline.How: Run the eval on a live model.
    • ConnectorConnectorEarn it as you goFor making your tool reusable by any MCP client, with the approval gate inside the server.How: Schedule a meeting through the MCP server in Claude Code (Path 2).
    • PolyglotPolyglotEarn it as you goFor running the same agent on a second LLM API, and seeing how little has to change.How: Run the agent or the eval on Gemini.
    • Kairos CompleteKairos CompleteEarn it as you goFor the whole journey: building an agent, measuring it, connecting it over MCP, and porting it.How: Earn the other four badges.

    The badges¶

    • First Agent

      Run the eval for free, then schedule a meeting with the Claude agent.

      Quickstart steps 2 to 4

    • Evaluator

      Run the eval on a live model: python evals/run_evals.py --models baseline,claude

      Run the eval

    • Connector

      Schedule a meeting through the MCP server, in Claude Code or Claude Desktop.

      Use Kairos over MCP

    • Polyglot

      Run the agent or the eval on Gemini, to see the same agent on another LLM.

      Claude and Gemini side by side

    • Kairos Complete

      Earn the other four. You've built an agent, measured it, connected it over MCP, and ported it.

    What counts as each milestone¶

    Milestone Recorded when
    Ran the eval for free run_evals.py runs with --models baseline or --replay
    Completed a full tool call with Claude claude_agent.py gets Claude's final reply after a tool call, whether you typed y or n
    Ran the eval on a live model run_evals.py calls Claude or Gemini
    Scheduled a meeting through MCP The MCP server's create_event creates an event
    Ran Kairos on another LLM gemini_agent.py completes a tool call, or the eval runs Gemini

    Typing n at the confirmation still counts: you completed the whole agent loop, and saying no is part of it.

    For every way to check your progress, see See your progress.

    Start over¶

    python progress.py --reset
